# Whole-array benchmarks

Generated by `src/benchmarks/benchmark-array.sh` on 2026-11-04.  Times are
wall-clock seconds (lower is better), including process startup.  syntran,
gfortran, and numpy are the best of 3 runs; pure python is a single run.

The syntran column is the interpreter.  The native column is an executable made
once by `syntran --native`, whose compile time is not counted, like gfortran's.
The jit column is `syntran --jit`, which compiles in memory on every run, so its
time includes the compile.  Both are best of 3 runs.

- CPU: Apple M5
- syntran: syntran 1.7.0 (`build/Release/syntran`)
- fortran: GNU Fortran (Homebrew GCC 16.1.0) 16.1.0, `-O2`
- python: 3.9.6, numpy: 2.0.2
