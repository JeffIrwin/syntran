# Whole-array benchmarks

Generated by `src/benchmarks/benchmark-array.sh` on 2026-10-08.  Times are
wall-clock seconds (lower is better), including process startup.  syntran,
gfortran, and numpy are the best of 3 runs; pure python is a single run.

- CPU: Apple M5
- syntran: syntran 1.6.0 (`build/Release/syntran`)
- fortran: GNU Fortran (Homebrew GCC 16.1.0) 16.1.0, `-O2`
- python: 3.9.6, numpy: 2.0.2

## Benchmarks

| name | workload |

| axpy | `a = a*0.999 + b`, 10M f64 elements, 50 iterations |
| elem | `b = b + sqrt(abs(a)) + exp(-a*a)`, 5M elements, 20 iterations |
| stencil | 1D heat equation via slices `u[1:n-1] += 0.25*(u[0:n-2] - 2*u[1:n-1] + u[2:n])`, 1M elements, 200 iterations |
| reduce | `sum(a*b) + a @ b + maxval(a-b)`, 10M elements, 50 iterations |
| matmul | `c = 1e-3 * (m @ c)`, 300x300, 20 iterations.  Native code finishes in tens of milliseconds here, so this row is dominated by process startup and its ratios are not meaningful |
